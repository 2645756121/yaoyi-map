四、WCAG AA 对比度验证摘要

所有"应该使用"的色彩组合都已经过 scripts/verify-wcag-contrast.mjs 验证。运行 node scripts/verify-wcag-contrast.mjs 可获取完整报告。

合规组合（实际使用）

#243B25 最深绿 / #F7EADF 米色 → 10.30:1 AAA #102514 标题绿 / #F7EADF → 13.72:1 AAA #243B25 / #F0D1A1 蜜炙桃黄按钮 → 6.5:1 AAA #587851 深绿 / #F7EADF 米色 → 4.22:1 AA 大文本 #587851 / #FFFFFF 白底 → 4.98:1 AAA 大文本

禁用组合（已被工程实践排除）

#F0D1A1 蜜炙桃黄 / #F7EADF 米色 → 1.5:1 FAIL #FFFFFF 白 / #90A686 草本绿 → 2.63:1 FAIL #587851 深绿 / #F0D1A1 蜜炙桃黄 → 2.35:1 FAIL #F0D1A1 蜜炙桃黄 / #FFFFFF 白 → 2.12:1 FAIL

五、应用清单

  • 页面主体：linear-gradient(180deg, #90A686 → #7A8F70) + 蜜炙桃黄径向高光
  • Header（导航栏）：深绿渐变 from-primary-700 via-primary-600 to-primary-700 + 米色文字
  • 草药目录区：极浅黄过渡 from-amber-50 to-amber-100/40
  • 地图容器：米色 #F7EADF + 米色边框 + 草本绿阴影
  • 侧边栏：米色渐变 #F7EADF → #FBF1E6 + 草本绿阴影
  • 弹窗：最深绿半透明蒙层 rgba(36,59,37,0.55) + 米色面板
  • 主按钮：蜜炙桃黄渐变 #F0D1A1 → #DDBE8C + 最深绿文字 #243B25
  • 次按钮：米色 #F7EADF + 草本绿边框 #90A686
  • 输入框：近白底 #FFFCF8 + 草本绿/蜜炙桃黄边框过渡
  • 滚动条：草本绿渐变 → hover 蜜炙桃黄加深

详细场景清单请参考 PALETTE_USAGE.md。
